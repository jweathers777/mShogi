# Standard shogi fixture inventory

MSH-62 planning inventory, 2026-10-26. **No fixture or shogi test implementation is delivered here.** Stable IDs reserve independently expected cases for future MSH-41 work. Every row needs an instantiated position/event record and fresh independent review before it can support delivery evidence. Concrete diagrams below are initial hand-derived expectations, not engine-generated answers or a certified reachable-game corpus. All profile-specific results remain conditional on SHOGI-P1; the proposed bundle is `mshogi.shogi.csa36.v1` in [the profile proposal](shogi-profile.md).

## Provenance and fixture admission

Source labels link to primary sources: [JSA-B1 initial arrangement](https://www.shogi.or.jp/knowledge/shogi/01.php), [JSA-B2 captures, drops and promotion](https://www.shogi.or.jp/knowledge/shogi/02.php), [JSA-B3 piece movement](https://www.shogi.or.jp/knowledge/shogi/03.php), [JSA-B4 check and mate](https://www.shogi.or.jp/knowledge/shogi/04.php), [JSA-B5 forbidden moves](https://www.shogi.or.jp/knowledge/shogi/05.php), [JSA-R codified rules, corrected 2025-10-01](https://www.shogi.or.jp/match/taikyoku_rules/taikyoku_rules.pdf), [CSA-36 event rules](https://www.computer-shogi.org/wcsc36/rule.pdf), and [USI specification](https://shogidokoro2.stars.ne.jp/usi.html). The profile document records editions, rule clauses and authority precedence. JSA-B educational material supplies diagrams/explanation; it does not silently override the dated governing profile. `LOCAL` below means a manually derived geometric/state expectation to be checked against the cited rule, not a new rule authority. `APP` means an accepted application boundary contract rather than an over-the-board rule.

Future concrete records must carry ID/version, rule-profile ID/version, source URL/edition/clause, human derivation and reviewer, root position, side, both hands, position-admission category, exact move or complete move set as appropriate, event sequence, expected state/actions/result and reason, known-history start, counters/clock policy, and any reference observations. Keep oracle observations separate from expected facts. Missing corpus/reviewer/decision data stays explicitly pending. When changing an expected answer retain its prior version and rationale.

Diagrams use USI coordinates. `B:` means Sente pieces, `W:` Gote, `+` a promoted piece; omitted squares are empty. Each diagram contains kings `B K9i`, `W K1a` unless overridden. Hands empty unless stated. This sparse local domain is not a claim of reachability from the full initial set. A future loader's analysis-position contract must explicitly admit it; otherwise use a reviewed full-material equivalent. Every relevant case needs a color-reversed/180-degree counterpart, with Sente/Gote points kept asymmetric where the profile requires them.
